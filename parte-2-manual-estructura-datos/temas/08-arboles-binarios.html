Definición

Un árbol binario es un árbol donde cada nodo tiene como máximo dos hijos: izquierdo y derecho.

Utilidad

Representar jerarquías, expresiones, decisiones y datos con relaciones padre-hijo; base de BST, heaps y árboles balanceados.

Características

  • Raíz: nodo superior sin padre
  • Hojas: nodos sin hijos
  • Altura: camino más largo de raíz a hoja
  • Recorridos: preorden, inorden, postorden, por niveles

Representación

class Nodo {
  int dato;
  Nodo izq;
  Nodo der;
}

Casos de uso

  • Árbol de expresiones aritméticas
  • Organigramas y carpetas
  • Compresión Huffman
  • Base de árboles de búsqueda

Ejemplo 1: Recorrido inorden

  1. Árbol: raíz 8, izquierdo 3, derecho 10; hijo izq de 3 es 1
  2. Inorden: izquierdo → raíz → derecho
  3. Subárbol izquierdo de 8: inorden de 3 con hijo 1 → 1, 3
  4. Visitar raíz 8
  5. Subárbol derecho: solo 10
  6. Secuencia inorden: 1, 3, 8, 10

Ejemplo 2: Calcular altura

  1. Si nodo es null → altura = 0
  2. Altura izquierda = altura(nodo.izq)
  3. Altura derecha = altura(nodo.der)
  4. Altura del nodo = 1 + max(altura izq, altura der)
  5. Para raíz 8 (subárboles alturas 2 y 1) → altura = 3
