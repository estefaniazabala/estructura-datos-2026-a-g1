Definición

Una lista doblemente enlazada tiene referencias prev y next. Una lista circular conecta el último nodo con el primero.

Utilidad

Permite recorridos bidireccionales y estructuras cíclicas.

Características

  • Más memoria por nodo
  • Inserción rápida
  • Recorrido adelante y atrás
  • Puede ser circular

Representación

class NodoDoble {
  int dato;
  NodoDoble prev;
  NodoDoble next;
}

Casos de uso

  • Deque
  • Buffers
  • Listas de reproducción

Ejemplo 1: Insertar al final

  1. Lista: 10 ↔ 20
  2. Crear nodo 30
  3. Actualizar referencias
  4. Nuevo tail = 30

Ejemplo 2: Lista circular

  1. A → B → C → A
  2. Recorrer hasta volver al inicio
