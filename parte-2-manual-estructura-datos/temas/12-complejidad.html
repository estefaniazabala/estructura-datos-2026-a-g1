Definición

La complejidad algorítmica describe cómo crecen el tiempo o la memoria que usa un algoritmo cuando aumenta el tamaño de la entrada n.

Utilidad

Comparar algoritmos y estructuras de datos de forma independiente del hardware; predecir rendimiento con entradas grandes.

Características

  • O (O grande): cota superior (peor caso habitual)
  • Ω: cota inferior
  • Θ: cota ajustada (mismo orden superior e inferior)
  • Se analiza tiempo y espacio auxiliar

Representación

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n)

Casos de uso

  • Elegir entre array, lista, hash o árbol según operaciones
  • Justificar optimizaciones en proyectos y exámenes
  • Entrevistas técnicas y diseño de sistemas

Ejemplo 1: Bucle anidado

  1. Código: for(i=0; i<n; i++) for(j=0; j<n; j++) trabajo constante
  2. El bucle interno corre n veces por cada i
  3. Total de iteraciones: n × n = n²
  4. Complejidad temporal: O(n²)

Ejemplo 2: Merge Sort

  1. Dividir el arreglo por mitades → log n niveles de división
  2. En cada nivel, combinar todos los elementos: O(n) por nivel
  3. n niveles × trabajo O(n) en cada uno → O(n log n)
  4. Espacio auxiliar del merge: O(n)
  5. Resultado: tiempo O(n log n), espacio O(n)
