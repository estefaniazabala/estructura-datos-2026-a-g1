Definición

Un array es una estructura que almacena elementos del mismo tipo en posiciones contiguas de memoria.

Utilidad

Permite acceso rápido mediante índices.

Características

  • Tamaño fijo o dinámico
  • Índices base 0
  • Inserciones en medio son O(n)

Representación

int[] notas = {85, 90, 78, 92};

Casos de uso

  • Inventarios
  • Calificaciones
  • Matrices
