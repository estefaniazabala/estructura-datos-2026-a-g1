Definición

Una tabla hash almacena datos usando una función hash para convertir claves en posiciones dentro de un arreglo.

Utilidad

Permite búsquedas e inserciones rápidas en promedio O(1).

Características

  • Usa pares clave-valor
  • Puede haber colisiones
  • Se usan buckets o sondeo
  • El factor de carga afecta el rendimiento

Representación

indice = hash(clave) % tamaño

tabla[indice] = valor

Casos de uso

  • Diccionarios
  • HashMap
  • Cachés
  • Bases de datos

Ejemplo 1: Función hash

  1. hash(k) = k mod 7
  2. 14 → índice 0
  3. 21 → índice 0 (colisión)
  4. 8 → índice 1

Ejemplo 2: Sondeo lineal

  1. 12 → posición 2
  2. 17 → posición 2 ocupada
