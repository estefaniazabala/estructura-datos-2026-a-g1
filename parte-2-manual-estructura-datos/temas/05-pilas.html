Definición

Una pila (Stack) es una estructura lineal LIFO (Last In, First Out): el último elemento que entra es el primero que sale.

Utilidad

Modela situaciones donde solo importa el elemento más reciente: deshacer acciones, validar sintaxis, llamadas recursivas y recorridos en profundidad.

Características

  • Operaciones: push (apilar), pop (desapilar), peek/top (ver tope)
  • Acceso únicamente al tope en O(1)
  • Implementación con array o lista enlazada

Representación

push(5) → [5]
push(3) → [5, 3]   // 3 es el tope
pop()   → devuelve 3, queda [5]

Casos de uso

  • Historial "Deshacer" en editores
  • Validación de paréntesis y expresiones
  • DFS iterativo en grafos y árboles
  • Pila de llamadas del programa

Ejemplo 1: Validar paréntesis balanceados

  1. Expresión: "({[]})"
  2. Leer '(' → push '('
  3. Leer '{' → push; leer '[' → push
  4. Leer ']' → pop debe ser '[' ✓
  5. Leer '}' → pop debe ser '{' ✓
  6. Leer ')' → pop debe ser '(' ✓
  7. Pila vacía al final → expresión válida

Ejemplo 2: Convertir decimal a binario

  1. n = 13
  2. 13 % 2 = 1 → push 1; n = 6
  3. 6 % 2 = 0 → push 0; n = 3
  4. 3 % 2 = 1 → push 1; n = 1
  5. 1 % 2 = 1 → push 1; n = 0 (fin)
  6. Pop en orden de salida: 1101₂
