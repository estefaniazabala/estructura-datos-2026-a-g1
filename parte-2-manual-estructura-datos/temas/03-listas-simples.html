Definición

Lista enlazada simple: colección de nodos conectados mediante referencias.

Utilidad

Permite inserciones y eliminaciones dinámicas.

Características

  • Recorrido secuencial
  • Memoria no contigua
  • Uso de punteros

Representación

class Nodo {
  int dato;
  Nodo next;
}

Casos de uso

  • Listas de tareas
  • Reproducción musical
